# 오존 핫스팟 진단기 (웹 배포판)

이동측정 자료(VOC + O₃/NO/NO₂/NOx + GPS)를 올리면 오존 핫스팟과
광화학 체제를 스크리닝하는 단일 페이지 도구입니다. 서버 없이 정적 파일만으로 동작하며,
업로드한 측정 자료는 브라우저 안에서만 처리되고 외부로 전송되지 않습니다.

버전 v16.5

## 파일 구조

    index.html              화면 구조와 스타일, 로더
    assets/app.js           분석 엔진 (기존 코드)
    assets/patch-pre.js     배경지도 목록 교체 (app.js 보다 먼저 실행)
    assets/patch-post.js    지도 도구 (배경지도 선택·회색/밝기·거리 측정·축척·좌표)
    assets/map-tools.css    지도 도구 스타일
    data/facilities.json    대기배출사업장 17,572곳 (경기 15,359 · 인천 2,213)
    .nojekyll               GitHub Pages 가 파일을 그대로 서빙하도록 지정

이 배포판은 데이터와 스크립트를 분리해 두었습니다. index.html 이 32KB 라 첫 화면이 바로 뜨고,
2.4MB 사업장 데이터는 뒤이어 내려받으며 브라우저 캐시에 남기 때문에 두 번째 접속부터는
거의 즉시 열립니다.

## 로컬에서 확인하기

파일을 더블클릭하면 동작하지 않습니다. 브라우저가 로컬 파일에서 다른 파일을 읽는 것을
막기 때문이고, 이때는 화면 아래에 안내 문구가 뜹니다. 웹 서버로 열어야 합니다.

    cd ozone-hotspot-web
    python -m http.server 8000
    # 브라우저에서 http://localhost:8000

인터넷 없이 파일 하나로 쓰셔야 하면 단일 파일 버전(index_v16.5.html)을 사용하세요.

## GitHub Pages 배포

    cd ozone-hotspot-web
    git init
    git add .
    git commit -m "오존 핫스팟 진단기 v16.5"
    git branch -M main
    git remote add origin https://github.com/<계정>/<저장소>.git
    git push -u origin main

GitHub 저장소 Settings → Pages → Source 를 `Deploy from a branch`, 브랜치를 `main` / `root`
로 지정하면 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.
이후 수정은 `git add . && git commit -m "수정 내용" && git push` 만 하면 자동 반영됩니다.

### 배포 전에 확인할 것

공개 저장소로 올리면 index.html, app.js, 사업장 데이터, 그리고 접속 코드까지 누구나
볼 수 있습니다. 접속 코드는 브라우저에서 실행되는 코드 안에 들어 있어 보안 장치가 아니라
단순한 진입 차단이며, 소스를 열면 확인됩니다. 부서 안에서만 쓰실 거라면 다음 중에 고르세요.

- 비공개 저장소 + Pages : GitHub Team/Pro 등 유료 플랜이 필요합니다.
- 공개 저장소 : 대외 공개해도 되는 내용인지 먼저 정리하고 올리세요.
- 파일 전달 : 단일 파일 버전을 메일·공유폴더로 돌리면 배포 없이 끝납니다.

업무망에서 GitHub 접속이 차단돼 있을 수 있으니, 동료분들이 실제로 열리는지 먼저 한 명에게
확인받아 보시는 편이 좋습니다.

## 배경지도

국내 지역은 해외 지도 서비스가 고배율 타일을 제공하지 않아(확대하면
"Map data not yet available" 타일이 내려옵니다) 국토지리정보원 VWorld 를 기본으로 씁니다.
헤더 드롭다운에서 VWorld 일반지도 · VWorld 항공사진 · Esri 위성 · OSM · 오프라인 격자를
고를 수 있고, 선택값은 브라우저에 저장됩니다. 지도가 아예 안 뜨는 환경에서는
오프라인 격자를 고르면 배경 없이 좌표 격자만으로 분석할 수 있습니다.

## 지도 도구

지도 오른쪽 위 패널에서 배경 회색도와 밝기를 조절합니다. 측정점 색이 잘 보이게
회색 55% · 밝기 105% 로 시작합니다. 거리 측정 버튼을 켜고 지도를 클릭하면 지점 간
누적 거리가 표시되고 ESC 로 끝납니다. 왼쪽 아래에는 축척 막대와 마우스 위치의
위·경도가 나옵니다. 논문 그림으로 캡처할 때 축척을 함께 담을 수 있습니다.
